# 🌍 Global Disaster Analysis Dashboard | Tableau

An interactive **Tableau dashboard** for analyzing global disaster events, human impact, economic damage, disaster trends, and country-level patterns from historical disaster data.

The dashboard transforms disaster records into an interactive analytical view that helps users explore the frequency, severity, geographic distribution, human impact, and economic consequences of disasters across different years, countries, and disaster types.

> **[🔗 View Interactive Dashboard on Tableau Public](https://public.tableau.com/app/profile/bhaskar.nakka4980/viz/DisasterAnalysis_17869126013330/Globaldashboard)**

## 🎯 Project Objective

The objective of this project is to analyze historical global disaster events and understand their impact on people, countries, and economies.

The dashboard provides an interactive view of:

- Global disaster frequency
- Human impact of disasters
- Economic damage caused by disasters
- Disaster trends over time
- Geographic distribution of disaster events
- Disaster types and their frequency
- Country-level disaster impact
- Relationship between disaster frequency and severity

## 📈 Dashboard Analysis

### 🌍 Global Disaster Overview

The overview provides a consolidated view of global disaster activity, including event frequency, affected population, deaths, and economic damage.

This allows users to quickly understand the overall scale of disaster impacts.

---

### 📅 Disaster Trends Over Time

The trend analysis explores how disaster activity has changed over time.

Users can examine:

- Disaster events by year
- Changes in disaster frequency
- Changes in human impact
- Historical patterns in disaster activity

---

### 🗺️ Geographic Analysis

The geographic analysis visualizes disaster impact across countries and regions.

This helps identify areas that have experienced significant disaster-related human impact and allows users to compare countries geographically.

---

### ⚠️ Disaster Type Analysis

The dashboard breaks down disasters by type to understand which categories occur most frequently.

Examples of disaster categories include:

- Floods
- Storms
- Earthquakes
- Extreme temperatures
- Droughts
- Wildfires
- Volcanic activity
- Other natural hazards

This allows users to compare disaster frequency across different event types.

---

### 👥 Human Impact

The human-impact analysis focuses on the people affected by disasters.

It helps users explore:

- Number of deaths
- People affected
- Deaths per disaster event
- Countries experiencing high human impact
- Disaster types associated with severe human consequences

---

### 💰 Economic Impact

The economic-impact section focuses on the financial consequences of disasters.

Users can analyze:

- Total economic damage
- Average damage per event
- Countries with significant economic losses
- Disaster types associated with higher economic damage

---

### 🏳️ Country Analysis

The country analysis allows users to examine disaster activity at the country level.

Users can compare countries based on:

- Number of disaster events
- Deaths
- People affected
- Economic damage

This provides a more detailed understanding of how disaster impacts differ geographically.

## 🗂️ Dataset

The project uses historical disaster data based on the **EM-DAT International Disaster Database** country-profile dataset.

The dataset contains information related to disaster events and their impacts across countries.

### Dataset Details

| Attribute | Description |
|---|---|
| Dataset Type | Historical Disaster Dataset |
| Format | CSV |
| Coverage | Global |
| Data Source | EM-DAT disaster data |
| File | `disaster-events.csv` |

The dataset contains disaster-related information used to analyze:

- Disaster events
- Countries
- Disaster types
- Deaths
- People affected
- Economic damage
- Historical disaster activity
